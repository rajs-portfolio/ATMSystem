# 🏧 ATM System in Java

A simple **ATM System** developed in **Java** using **Object-Oriented Programming (OOP)** concepts. This project allows users to perform basic banking operations such as checking balance, depositing money, and withdrawing money through a menu-driven console interface.

---

## 📌 Features

- 💰 Check Account Balance
- ➕ Deposit Money
- ➖ Withdraw Money
- ❌ Exit the Application
- ✅ Input Validation
- 🔄 Menu-Driven Interface

---

## 🛠️ Technologies Used

- Java
- Scanner Class
- Switch Case
- Methods
- Loops
- Conditional Statements

## ▶️ How to Run

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/ATM-System.git
```

### 2. Navigate to the Project Folder

```bash
cd ATM-System
```

### 3. Compile the Program

```bash
javac ATMSystem.java
```

### 4. Run the Program

```bash
java ATMSystem
```
